# Release notes and "what's new" tours

**Who it's for:** Product managers announcing changes.

## The problem

Release notes describe a change, but users still cannot find the new button.

## How Demo Anything helps

- Show the change in a three- or four-step tour that ends on the new feature.
- Link the tour from the release note or an in-app banner.
- Each tour is small, so it is quick to make for every release.

## Steps

1. Capture the path to the new feature.
2. Write one line about why it matters.
3. Publish it alongside the release note.

See [getting started](../getting-started.md) and [building flows with an agent](../agent-workflow.md)
for the details, and [redaction](../redaction.md) before you publish anything real.
